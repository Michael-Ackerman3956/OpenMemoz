THE MODEL

Two pipelines, labelled honestly.

This is the concept doc's central rule, and it becomes the product's best feature.

TIER 1 · direct pull
·
RSS or an official API
·
Headline + excerpt + link, as-is
·
Never rewritten

HN · TechCrunch · SEC EDGAR · Federal Reserve · BLS · BEA · ScienceDaily · Frontiers · PubMed · MLX · MercoPress

TIER 2 · AI-synthesized
·
Search-grounded summary
·
2–3 sentences + visible citations
·
Never another outlet's verbatim text

Used only where no direct feed is cleared: world news, positive news, local

Stated plainly in the doc

Tier 2 is a different risk posture, not a clean one. AP v. Meltwater sank verbatim redisplay; News Corp v. Perplexity contests synthesis. Keep citations visible, never claim verification.

THE ANGLE NOBODY ELSE HAS

Tell the agent what it may trust.

Every tool returns a provenance tier. An agent summarising your paper knows which sentences are quotable and which are generated.

{
  headline: "Fed Holds Rates Steady",
  tier: 1,                        // verbatim, safe to quote
  source: "Federal Reserve Board",
  licence: "public domain · 17 U.S.C. §105",
  url: "https://…"
}

Most entries will expose content. Exposing content plus its licence and confidence is a genuinely novel WebMCP idea, and it comes free from work you already did.

THE DESIGN ARGUMENT

What we deliberately withhold.

Every shipped WebMCP app stops short of its irreversible step. Ours has almost none — so we invent the honest ones.

Not a toolWhy
publish_editionAn edition is a dated public artefact. A person decides when one exists.
delete_sourceRemoval is destructive and silent. Muting is reversible; deleting is not.
rewrite_storyTier 1 text is never rewritten. That rule is the whole legal position.
promote_to_tier_1Only a licence audit moves a source between tiers, not an agent.
The agent can read everything, rearrange anything, and change what tomorrow looks like — but it cannot put words in a source's mouth.

WHAT THE CODE LOOKS LIKE

One tool, complete.

Note the description does the real work — it tells the model what tier means.

useWebMCP({
  name: "search_stories",
  description:
    "Search today's edition. Each result includes a provenance tier: " +
    "tier 1 is the source's own text and may be quoted; tier 2 is an " +
    "AI summary and must not be presented as a quote.",
  inputSchema: {
    type: "object",
    properties: {
      query:   { type: "string", description: "Words to match in headline or excerpt" },
      section: { type: "string", description: "Optional section to narrow to" },
    },
    required: ["query"],
  },
  annotations: { readOnlyHint: true },
  execute: ({ query, section }) => searchEdition(query, section),
});

Same pattern nine times. The descriptions are the deliverable, not the plumbing.

THE IRREVERSIBLE DECISION

You can close the future. Not the past.

The challenge requires a public repo with a visible OSS licence, so this choice happens on day 1.

Already publishedPermanent. Anyone who received it keeps that grant forever.
Future versionsYou may relicense — only if you hold all the copyright.
If you merge a PRYou lose that ability, unless you took a CLA first.
RecommendedAGPLv3, matching MailPidge CE. Add a CLA before accepting any contribution.
Because the doc plans a $4.99/mo tier

Publish the generator and the WebMCP layer. Keep personalization, the interest graph, and email delivery out of the public repo — they are Phase 2+ and not needed to win.
