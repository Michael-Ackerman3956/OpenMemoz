CONCEPT

DailyPress

An AI newspaper assembled from legally-cleared sources.
The reader's own browser agent helps them read it.

Sources (RSS/API)  →  AI Editor  →  edition.json  →  Static Site (Vercel)
                                                      + WebMCP tools
                                                      + Email (CF Workers)
The idea
·Tier 1 — direct pull from cleared feeds, displayed as-is
·Tier 2 — AI reads the web, generates original summary with citations
·WebMCP — browser agent searches, explains, retunes the paper
·Cost — $0/mo to run (free tiers everywhere)

PHASES

Four phases.

Phase 1 — Static Generator (2 weeks)
·6-10 Tier 1 sources, one daily edition
·3 layout modes (Dynamic, Traditional, Simple)
·Provenance badges on every story
·Cron at 6 AM, deploy to Vercel
Phase 2 — Personalization (3-4 weeks)
·Interest tags → embedding-based ranking
·Per-user editions, email delivery
Phase 3 — Smart Layout (3-4 weeks)
·AI auto-selects layout mode per edition
·Per-user engagement analytics
Phase 4 — Conversational (2-3 weeks)
·"Talk to your editor" via WebMCP tools
·No chat UI needed — the agent IS the interface

CONTENT MODEL

Two tiers, labelled honestly.

Every story carries provenance. The agent knows what it can trust.

Tier 1 — Direct Pull
·RSS or official API
·Headline + excerpt + link, as-is
·Never rewritten, never AI-touched
·Safe: public domain, CC, or explicit ToS grant
Tier 2 — AI-Synthesized
·Search-grounded summary (Gemini)
·2-3 sentences + visible citations
·Never another outlet's verbatim text
·Disclosed as AI-generated (dashed badge)
