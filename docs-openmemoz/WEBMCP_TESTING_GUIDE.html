03 / 12
Required for all methods

Enable the Chrome flag

This unlocks document.modelContext in Chrome. Without it, your tools silently don't register. Every testing method below needs this.

1

Check Chrome version (need 149+)

chrome://version
2

Enable WebMCP flag

chrome://flags/#enable-webmcp-testing

Set to Enabled → click Relaunch

  • search_stories — query "climate" returns matches
  • get_story — pass identifier, get full story
  • get_reading_context — shows filter state + count

12 / 12
Troubleshooting

If things don't work

Tools don't appear anywhere

Chrome flag not enabled, or Chrome version below 149.

Check console for errors from webmcp.ts.

YouTube tool returns error

Test the API route directly:

your-site.vercel.app/api/youtube/metadata?url=https://youtube.com/watch?v=dQw4w9WgXcQ

Write tools don't persist

Check localStorage in DevTools → Application → Local Storage.

Look for keys starting with newsroom_edition_.

Agent reads HTML instead of calling tools

That agent doesn't support document.modelContext yet.

Fall back to the Demo Harness (/demo) or Inspector Extension.

Compat note: Your codebase checks both document.modelContext (Chrome 150+) and navigator.modelContext (Chrome 146-149).
