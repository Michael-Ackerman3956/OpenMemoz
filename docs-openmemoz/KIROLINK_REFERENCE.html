KiroLink SAVE FOR LATER

Use Kiro's free-tier Claude credits inside Claude Code via a local proxy

Claude Code → localhost:8080 (kirolink proxy) → AWS CodeWhisperer (Kiro backend)

How It Works

kirolink reads your Kiro auth token, starts a local server that speaks the Anthropic API, and translates requests to Kiro's backend. Claude Code thinks it's talking to Anthropic directly.

Setup (when ready)

  1. Make sure kiro-cli is logged in (token at ~/.aws/sso/cache/kiro-auth-token.json)
  2. Clone & build: 
    git clone https://github.com/alexandephilia/kiro-claude-proxy
cd kiro-claude-proxy
go build -o kirolink kirolink.go
  3. Start the proxy: 
    ./kirolink server
  4. In a new terminal, export env vars: 
    eval "$(./kirolink export)"
  5. Run Claude Code normally — it routes through the proxy automatically

Available Models (via proxy)

claude-sonnet-4-6
claude-opus-4-6
claude-sonnet-4-5
claude-haiku-4-5
(+ aliases — run ./kirolink server then GET localhost:8080/v1/models)

Commands

./kirolink read          # show cached token (don't screenshot this)
./kirolink refresh       # refresh expired token
./kirolink export        # print ANTHROPIC_* env vars
./kirolink claude        # patch ~/.claude.json for Claude Code
./kirolink server [port] # start proxy (default 8080)
Catches: Limited to Kiro free-tier rate limits. If Kiro changes auth flow, proxy may break. Token must be refreshed if it expires. You still need Go installed to build.
