THE WHOLE IDEA IN SIX LINES

Same function. You just gave it a label.

This is the part that makes your "it sounds like a function" instinct exactly correct. Nothing about the function changes. You wrap it once so something other than a mouse click can reach it.

TODAY — ONLY A HUMAN CAN TRIGGER IT
sendBtn.onclick = () => checkCompliance(sheetUrl);
AFTER — A HUMAN OR AN AGENT CAN
document.modelContext.registerTool({
  name: "check_compliance",
  description: "Check the legal gates for a list.",
  inputSchema: { /* sheetUrl: string */ },
  execute: () => checkCompliance(sheetUrl),  // same fn
});

The only genuinely new bytes you write are the name and the description. That's the whole invention: a label an AI can read, attached to code you already shipped.
