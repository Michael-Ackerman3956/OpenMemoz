Newsroom Agent

WebMCP Challenge — Demo Video Script (under 3 minutes)

0:00 – 0:15 Hook
What if websites could talk to AI agents — not through scraping, but through structured tools? This is Newsroom Agent — the first WebMCP-powered newspaper that AI agents can read, write, and learn from.
🖥 Show: Newspaper front page, slow scroll revealing headlines and hero image
0:15 – 0:30 What Makes It Different
It looks like a newspaper. But under the hood, it exposes 25 WebMCP tools that any AI agent can call — to search stories, add content, change the layout, and even remember what you like to read.
🖥 Show: Quick flash of Settings page or the Demo page showing tool list
0:30 – 1:15 Live Demo — ChatGPT Reads & Writes
Let me show you. I'll open ChatGPT's built-in browser, go to the newspaper, and ask it to find and add stories — all in one go.
💬 Type in ChatGPT: "Search this page for AI stories, then add 2 Premier League stories with images to a new Sports section"
⏳ Wait: ChatGPT discovers tools, chains search_stories → add_story calls. Narrate while waiting: "It's reading the page's tools... found them... now it's adding stories..."
👁 Show: Stories appear on the newspaper in real-time. Point out the new Sports section and story count increasing.
The page updated live. New stories, new section, with images — all through WebMCP tools. And watch — I'll refresh the page.
🖥 Do: Hit refresh in the browser. Stories are still there. Say: "Still there. Persisted in localStorage."
Tip: Pre-load the page before recording so tools are already discovered. Saves ~30s of loading. If ChatGPT is slow, narrate what's happening to fill dead air.
1:15 – 1:45 The Differentiator — Memory
Most WebMCP sites are stateless. Every interaction starts from zero. Newsroom Agent is different — it remembers.
It tracks which stories you click, how long you spend reading. And the agent can save what it learns — and recall it next session. No server. All local.
💬 Type: "What have I been reading? Remember my preferences for next time."
👁 Show: ChatGPT calls get_reading_history, reasons about patterns, then calls save_memory. Point out the agent's reasoning.
The agent just learned something about this reader — and it'll remember it next time. That's the feedback loop: read, track, learn, personalize.
1:45 – 2:10 Theme Control
The agent can even restyle the entire newspaper. Thirteen color palettes, three visual styles — thirty-nine combinations.
💬 Type: "Switch the newspaper to the Terminal theme with glass visual style"
👁 Show: Page transforms in real-time — green-on-black terminal look with frosted cards
All through WebMCP tools. The user can also change themes themselves in Settings.
🖥 Quick flash: Settings page showing palette grid and live preview
2:10 – 2:30 Close
Twenty-five WebMCP tools. Read, write, favourite, reorder, personalize, restyle, remember. Thirty-nine theme combinations. All controllable by the agent or the user.
The web isn't just for humans anymore — it's for agents too. Newsroom Agent. Open source. Apache 2.0.
🖥 Show: URL bar with newsroom-agent-mcp.vercel.app clearly visible. Hold for 3 seconds.

Pre-Recording Checklist

ChatGPT desktop app open, new chat ready
Page loaded in ChatGPT browser (tools pre-discovered)
Second browser tab on Settings page (for quick flash)
Screen recording ready (Cmd+Shift+5 or OBS)
Read a few stories first (so reading history has data)
Close notifications, hide desktop icons
Microphone tested and working
Clear localStorage if you want a clean slate (DevTools → Application → Clear)
